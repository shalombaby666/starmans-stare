# Starman’s Stare — согласованная концепция

Русскоязычный образовательный космический веб-клуб в эстетике 1998 года. Название и декоративные надписи могут быть английскими. Пользователь согласовал направление и начало реализации 13 ноября 2026.

Главная — звёздное поле и планеты как навигация, хромированное название, баннеры 88×31, вымышленная реклама. Досье и инструменты используют оконные рамки. Палитра: чёрный космос, navy, циан, жёлтый, фуксия и серебро. Основной текст читаемый; контраст, клавиатура, мобильный экран и уменьшение движения обязательны.

Первая версия: восемь планет, 11 выбранных спутников, сравнение параметров планет, библиотека проверенных внешних ресурсов, видеотека с явным переходом на внешний источник, локальный журнал изученных объектов. Положения на карте и размеры условные. Данные NASA с источниками; не обещать полный каталог спутников. Счётчик посещений не имитирует реальную аналитику.

Архитектура: React + TypeScript + Vite, статические данные, CSS/SVG иллюстрации, localStorage с обработкой ошибок. Без регистрации и сервера. GitHub Pages workflow; сборка пригодна для статического хостинга. Публикация требует доступного подключения к GitHub; локальный репозиторий сохраняется при отсутствии доступа.

## Уточнение направления

По замечанию пользователя от 13 ноября 2026: усилена эстетика личной страницы 90-х. Системные Times New Roman, Arial Black / Impact, Courier New, Comic Sans MS; яркие синий, жёлтый, циан, звёздный фон, панели Windows. Добавлены отсылки к Автостопом по галактике, HAL и Major Tom без музыки и чужих изображений. Рабочие разделы: архив трёх событий, викторина из пяти вопросов и каталог ссылок с локальными закладками. Пользователь подтвердил направление и попросил загрузить черновик на GitHub.
